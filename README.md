# L'Walida — الوالدة

### Every street holds a memory.

A spoiler-light 2D narrative adventure set in Rabat, Morocco. A young man returns with an old photograph of his mother's childhood door and reconstructs the memories attached to the places she loved.

**Engine:** Unity 6 (`6000.3.16f1`)  
**Render pipeline:** Universal Render Pipeline 2D (`17.3.0`)  
**Input:** Unity Input System (`1.19.0`), keyboard/mouse  
**UI:** uGUI (`2.0.0`) with the built-in LegacyRuntime font  
**Status:** Playable MVP implemented; Windows standalone build remains blocked by the missing build-support module.

## Play

1. Open this folder in Unity Hub with **6000.3.16f1**.
2. Let Unity import the generated assets.
3. Open `Assets/_Game/Scenes/01_MainMenu.unity`.
4. Press Play.

If the scene list looks incomplete after import, close and reopen the editor, or run `LWalida > Build or Update MVP Scenes`.

## Implemented MVP Features

- Main menu with New Journey, save-aware Continue, Settings, Credits and Exit.
- Intro cinematic with subtitles and skip confirmation.
- Side-scrolling exploration in Café Maure, Oudaya, Souk, optional Hassan Tower and Home.
- Three-door photography puzzle with a reference photo and distinct wrong-door feedback.
- Two NPC conversation chains with choices: Lalla Amina and Allal.
- Three-second sound-recording interaction with cancel and honest placeholder-audio feedback.
- Four unique memories, event-driven journal, locked cards and audio playback.
- Gated progression: all four memories are required before returning home.
- Home cutscene, memory photo row, credits and return to menu.
- Pause, journal, settings and restart confirmations.
- Master/music/ambience/dialogue/effects volume, subtitles, fullscreen, reduced flashes and reduced motion.
- Versioned local JSON checkpoint save/continue, with safe missing/corrupt-save handling.
- Deterministic procedural placeholder art and audio, generated by editor tooling.
- Editor pipeline for data, prefabs, scenes, build-settings registration and validation.
- EditMode and PlayMode automated tests.

## Screens and Content

The playable route is:

`Main Menu → Intro → Café Maure → Oudaya → Souk → optional Hassan Tower → Home → Credits`

All content is fiction inspired by Rabat. No real voice recordings are included. Dialogue is subtitle-based, with an explicit placeholder notice for the sound memory.

## Editor Setup and Rebuild

Open `LWalida` in the menu bar:

- **Build or Update MVP Scenes** — generates missing assets/data/prefabs and preserves existing scenes.
- **Rebuild MVP Scenes** — explicitly overwrites only the eight generated MVP scenes after confirmation.
- **Generate Missing Placeholders** — adds missing procedural art/audio without overwriting existing files.
- **Validate Project** — checks catalog, dialogue, scenes, prefabs and build settings.
- **Build Windows** — blocked in this environment because Windows Build Support is not installed.

Existing supplied art and non-null catalog assignments take precedence. See `docs/ASSET_GUIDE.md` for replacement instructions.

## Actual Dependencies

URP 2D, Input System, uGUI, 2D Sprite, Test Framework, Timeline package (installed; core game does not require Timeline), plus standard Unity modules. The project does **not** use Cinemachine or TextMeshPro. The installed Timeline and Visual Scripting packages are not required by the MVP.

## Build

A Windows standalone build requires **Windows Build Support (Mono/IL2CPP)** in Unity Hub. This machine currently has no Windows playback engine installed, so no standalone build was produced. After installing the module, run `LWalida > Build Windows`; the output is `Builds/Windows/LWalida.exe`.

The story deals with family, memory and grief, including the loss of a parent. It does not use jump scares or graphic imagery.

## Known Issues

- No Windows build was produced because Windows Build Support is missing.
- The Arabic title uses the built-in font as a fallback; shaping is not guaranteed. Supply `titleArabic` as a transparent PNG for reliable display.
- No authored character art, original Darija voice acting or authentic field recordings are included.
- Audio is procedurally generated placeholder material, not a substitute for final sound design.
- The environment JPGs have varying aspect ratios and are tiled/cropped deliberately; authored 16:9 or panoramic replacements are preferable.
- A full manual keyboard playthrough still needs to be completed in the editor; automated tests cover data, scenes, menu boot and compilation, not the whole narrative route.
